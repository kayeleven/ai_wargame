Title · Unchanged

Inspection schedule

Description · Changed

Saved base · Full text

Request inspections before each cargo shipment arrives. The logistics lead will agree a morning window with port staff and distribute the schedule to all participating teams.

Two observers will attend each inspection. Record cargo identifiers and quantities in the shared register; publish a summary at the end of each day. Any discrepancy goes directly to the port manager.

If access is delayed, hold the shipment until the inspection can take place. Review the timetable at the end of the turn and carry outstanding inspections into the following turn.

Proposed · Full text

Request inspections after cargo checks are complete. The team liaison will agree morning or afternoon windows with port staff and distribute the schedule to the teams affected by each shipment.

One observer and a port representative will attend each inspection. Record cargo identifiers, quantities and unresolved questions in the shared register; circulate a summary after each inspection. Refer discrepancies to the joint coordination group.

If access is delayed, ask port staff to identify which urgent deliveries may proceed under the existing rules. Revisit the timetable after each delay and record outstanding inspections before the turn closes.
